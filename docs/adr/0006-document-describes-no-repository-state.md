# This repository describes no repository state

This README records preferences and reference rulesets only. It never states which rulesets are active in this repository, what their identifiers are, or whether the preferences below are currently applied here.

Two reasons. A document that doubles as an audit of its own repository goes stale the moment someone edits a setting in the web UI, and it does so silently — the reader has no way to tell which sentences are current. And a live state record invites a category error: a repository reading these references would start treating this repository's configuration as part of the standard.

## Consequences

State is read from GitHub, not from this file. Specifically, the URLs and prose below must not gain branches such as "currently enabled in this repository". The one exception is the UI navigation paths that remain in the document: those describe where a setting lives in GitHub's interface, which is a property of GitHub, not of any repository.
