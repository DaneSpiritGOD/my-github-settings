[`README.md`](README.md) is the reusable artifact: consuming repositories fetch it through the raw-URL prompt at its top.

Editorial invariants:

- Settings are opt-in references, never requirements. Do not turn a preference into a mandate.
- `README.md` states desired end states only. Do not add execution steps or commands — invocations rot.
- `README.md` describes no current repository state. Never add "currently enabled here".
- Keep `README.md` self-contained: a consuming agent may see only that file and the links in it.
